# Support

Use GitHub issues for reproducible bugs and feature requests. Include the TADOSS revision or release, Kubernetes version, profile and commands used. Attach a reviewed redacted support bundle when relevant; do not attach Secrets, raw credentials or customer payloads.

Follow [troubleshooting](docs/how-to/troubleshooting.md) before opening an issue. This project provides community support without an uptime or response-time commitment. Vulnerabilities belong in the private process described in [SECURITY.md](SECURITY.md).
