# Security reporting

Report vulnerabilities privately through the repository's GitHub security advisory reporting channel. If private reporting is unavailable, contact the repository owners through their published organisation contact before sharing exploit details publicly. Include affected revision, reproduction and impact; omit production credentials and customer data.

This pre-release project supports the current main branch and published current release only. There is no response-time guarantee. Dependency audits run in pull requests and on a recurring schedule; release images are scanned and signed. A clean scan does not replace operational hardening or recovery testing.
